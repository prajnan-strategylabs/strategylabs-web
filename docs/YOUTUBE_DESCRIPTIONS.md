# YouTube Descriptions — Strategy Labs

Three things you'll need for the channel: the **About description**, a reusable **per-video description template**, and the channel **metadata** (handle, keywords, links).

---

## 1. Channel "About" description

Paste this into YouTube Studio → Customization → Basic info → Description. ~810 characters, well under 1000.

```
Strategy Labs is the plain-English crypto backtesting engine. Describe a trading
idea in words → we compile it to executable rules → backtest across 9 years of
crypto data → verdict in 30 seconds. No code. No Pine Script. No Python.

The flagship strategy V22 has a +953% audited cumulative return since Aug 2017
(2,410 trades, 49.3% win rate, Sharpe 2.84). The year-by-year audit — including
the years it lost money — is public at strategylabs.trade.

What you won't find here: hype, "guaranteed" returns, secret indicators,
financial advice. We make a tool, not predictions.

→ Try the engine free:  https://strategylabs.trade
→ Daily on X:  https://x.com/StrategyLabs
→ Telegram alerts:  https://t.me/StrategyLabsBot

Educational tool. Not financial advice. Past performance does not predict future
results.
```

**Why it reads this way (and the content slate is gone):**
- First line is the elevator pitch — it ranks in search and shows as the snippet.
- V22 is positioned as **proof of the engine**, not the channel's identity.
- "What you won't find here" is anti-positioning — pre-filters audience.
- Content-slate listings ("our weekly series", "tutorials", etc.) were removed — viewers see content as it ships, and promising it upfront is filler that bloats the description without convincing anyone.
- Disclaimer is mandatory and final.

**Why this template:**

- The boilerplate "About" at the bottom is your reusable brand strip
- Hashtags help discovery on the algorithmic feed

## 4. Short description for search / preview (first 160 chars)

YouTube search snippets often truncate to ~160 chars. The first sentence of your About description must land. The current opener does:

> *"Strategy Labs is the plain-English crypto backtesting engine. Describe a trading idea in words → we compile it → backtest across 9 years → verdict in 30 sec."* (158 chars)

That's what shows in YouTube search results. Don't bury the pitch.
